Secure Deep Linking for Magic Moments

The desktop companion client bridging your browser-based Magic Moments (MaMo) deck builder directly to your local Forge game client.

Download Desktop Installer

Core Companion Features

🔌

URI Protocol Handler

Registers the secure custom mamo:// protocol handler locally. Triggers launch events automatically when links are clicked in the browser.

🃏

Forge Deck Generator

Automatically downloads Magic: The Gathering deck definitions from the API and generates clean Forge-compatible deck files directly in your local directory.

🎮

Forge Replay Launcher

Launches local Forge game replays with pre-configured playtest parameters, providing a unified flow from the browser to the game client.

How It Works

1

Install the Desktop Client

Download and run the installer. The connector automatically registers its protocol scheme (mamo://) with the operating system.

2

Build in the Browser

Assemble your deck on the Magic Moments deck building website and click "Playtest" or "Launch Replay".

3

Automated Hand-off

The browser hands off the request to the local MaMo Connector, which sets up the local deck files and boots the Forge game client instantly.
