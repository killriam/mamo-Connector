# MaMo Connector — Claude Code Instructions

> See `.github/copilot-instructions.md` for full conventions. This file adds Claude-specific guidance.

## Key Rules

1. **Rust 2024 edition** — use latest idioms, no deprecated patterns
2. **No `unwrap()` in production code** — always use `?` or explicit error handling
3. **Platform-aware** — use `cfg!(target_os)`, test Windows paths and registry ops
4. **Forge `.dck` format is strict** — match Forge's parser exactly
5. **Single-instance model** — don't break the lock file mechanism
6. **English only** — all code, comments, documentation

## Architecture

```
main.rs → deeplink.rs (parse URL) → commands.rs (dispatch) → deck.rs / forge.rs / gamelog.rs
                                                                ↓
                                                          settings.rs (persist)
                                                                ↓
                                                            ui.rs (display)
```

## Cross-Repo Impact

- Deck fetching uses `new-backend` API — endpoint changes affect `deck.rs`
- Game log upload format must match `mtg-replay-notation` spec
- Deeplinks are generated by `MaMoFrontend` — URL format changes need coordination
